# WIL-PROJECT

 ---Tupac Salon & Barbers---

A complete web and mobile application system designed for "Tupac Unisex Salon & Barbers", enabling customers to book appointments, stylists to manage their schedules, and administrators to oversee business operations such as salary calculations, credit management, and service listings.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

# Overview

The Tupac Salon & Barbers System is a full-stack project consisting of:

1. Website – Developed using HTML, CSS, and JavaScript (via Visual Studio Code). Integrated with Firebase for real-time data management.
2. Mobile Application (Android) – Developed using Android Studio and integrated with Firebase for real-time data management.

The project allows smooth coordination between clients, barbers, and administrators.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

# Key Features

* For Customers:
- Register, log in, and manage personal profiles.
- View available stylists and services.
- Book, modify, or cancel appointments.
- View approved reviews and service details.

* For Stylists (Barbers):
- View daily and monthly schedules.
- Manage appointment availability.
- View earnings and salary breakdowns.

* For Administrators:
- Manage users, services, and appointments.
- Access the Salary Calculator to compute monthly barber payments.
- Use the Credit Manager to track borrowed amounts by barbers.
- Approve or reject customer reviews.
- Oversee system-wide operations and reports.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------


# Website Pages

1. **Home Page** – Salon overview and slideshow of images.  
2. **Services Page** – Displays all offered services and prices.  
3. **Booking Page** – Allows customers to make or modify bookings.  
4. **View Appointments Page** – Displays user appointment history and status.  
5. **Admin Dashboard** – Overview of salon operations.  
6. **Salary Calculator Page** – Computes and displays barber salaries.  
7. **Credit Manager Page** – Records and manages borrowed amounts.  
8. **Login & Signup Pages** – For all users (single table with role-based access).  

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## 📱 Mobile App Features

- Firebase Authentication for login and signup.  
- Real-time appointment management using Firestore.  
- Service browsing and booking system.  
- Admin access to salary and credit management features (via Firebase).  
- Simple and responsive UI for Android devices.
